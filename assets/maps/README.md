# Map Images

This folder contains local map images used by the Map Viewer and overlay.

Image sets:

- `steam-isometric`: high-resolution isometric map layouts from the Steam guide `Dead by Daylight - Maps (isometric) update 9.2.0`.
- `wiki-outlines`: outline/icon fallback images from the Official Dead by Daylight Wiki.

The app matches images by filename, so names like these are intentional:

```text
coal-tower-steam-isometric-01.jpg
coal-tower-wiki-outline.png
the-game-lower-floor-wiki-outline.png
nostromo-wreckage-wiki-map-icon.png
```

You can add more images here at any time. In the app, open `Map Viewer` and click `Refresh Images`.

Sources:

- Steam guide: https://steamcommunity.com/sharedfiles/filedetails/?id=2899093390
- Official DBD Wiki map outline images: https://deadbydaylight.wiki.gg/wiki/Category:Map_outline_images
- Official DBD Wiki map images: https://deadbydaylight.wiki.gg/wiki/Category:Map_images
